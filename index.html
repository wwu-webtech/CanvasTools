Canvas Tools

CanvAccommodation

A browser tool for your own Canvas courses. It runs inside a Canvas tab you are already signed in to, using your own account and your own permissions. No tokens, nothing to install.

CanvExporter

Saves a Canvas course as Word documents and Excel spreadsheets you can actually open, read, and print. No account, no access token, nothing to install.

CanvSyllabus

Turn a Word (.docx) syllabus into clean formatting you can paste straight into your Canvas Syllabus page. It runs entirely in your browser. Your file is never uploaded anywhere.

A bookmarklet is a browser bookmark that runs a small tool on the Canvas page you already have open. The bookmarklets run inside your own signed-in Canvas session, so they can only see and change what you already can, and they only work with WWU Canvas. There's nothing to install and no password or token to hand over, the source code is public for anyone to read at github.com/techconsigliere. Deleting the bookmark removes the tool completely. Chris Powell, WWU's Canvas LMS Administrator, built and maintains these tools, so if you'd like a walkthrough before trying one, please email canvashelp@wwu.edu.
